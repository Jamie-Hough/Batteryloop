# Batteryloop

Interactive techno-economic model for lithium-ion battery recycling built in Python and Streamlit

## Project Objectives

Estimate the profitability of lithium-ion battery recycling using engineering mass balances and economic analysis.

## Features

- Mass balance
- Revenue calculations
- Operating costs
- Sensitivity analysis
- Interactive Streamlit dashboard

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Streamlit
